## Project Description:
Collegium is a college-level platform designed for buying, selling, and exchanging goods among students within a campus. It provides a secure and user-friendly environment where students can list products, browse available items, and connect with each other for transactions. The platform ensures trust and safety by allowing access only to verified college users.

---

## Key Features:
- Secure user registration and login (college-based verification)
- Product listing with images and descriptions
- Search and filter functionality
- User profiles and activity tracking
- Responsive and user-friendly interface
